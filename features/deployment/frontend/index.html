    🚀 Dev Deployment Console — Overview & Quickstart
    
                    
    Welcome to the Dev Deployment Console, the local developer cockpit for building, testing, packaging, and deploying mobile apps with zero cloud dependencies.
    
                    
    
                        Quick Navigation: Explore the sidebar for full documentation including Conventions & Security, Workspaces & Apps, Build Jobs, APK/IPA OTA QR codes, Diagnostics, Universal Webhooks, and Mobile Innovations.
                    
    
                
    

            
            
    
                
                
                
    
                    
    Installation & Setup Guide 🛠️
    
                    
    Zero-dependency, local-first developer console running directly on Python ≥ 3.10 without pip or npm.
    
                    
    
                    
    Quickstart (30 Seconds)
    
                    
    # 1. Clone & enter repository
git clone https://github.com/sunilbvb/dev-deployment.git
cd dev-deployment

# 2. Launch Console
./start.sh
    
                    
    Validates Python ≥ 3.10, generates a local bearer authentication token, and opens the console in your default web browser.
    
                    
    1-Click System Launchers
    
                    
      
                        
    • Linux Desktop Menu Launcher: Installs native shortcut in ~/.local/share/applications/dev-deployment.desktop.
      • 
                        
    • Systemd User Service: Launches automatically on login as a background user daemon (dev-deployment.service).
      • 
                    
    
                
    

                
                
    
                    
    System Requirements & Prerequisites 📋
    
                    
    Minimal system requirements to run the console and build mobile applications.
    
                    
    
                    
    Host Environment
    
                    
      
                        
    • Python: Python ≥ 3.10 (3.10, 3.11, 3.12, 3.13, 3.14+). 100% standard library only.
      • 
                        
    • RAM: 512 MB for console runtime (8 GB+ recommended for Flutter/native compilation).
      • 
                        
    • Disk: 50 MB for console code.
      • 
                        
    • Browser: Modern evergreen browser (Chrome 90+, Edge 90+, Firefox 90+, Safari 15+).
      • 
                    
    
                    
    Optional Build SDKs
    
                    
    Required only when compiling corresponding build artifacts:
    
                    
      
                        
    • Flutter SDK (≥ 3.0.0), Android SDK (API 21-35), Xcode 14+, Fastlane, and Android Platform Tools (adb).
      •

    Contributing to Dev Deployment Console 🤝
    
                    
    Guidelines for submitting code, adding features, and maintaining standards.
    
                    
    
                    
      
                        
    • Zero External Dependencies: Must run 100% on Python standard library. Never add pip requirements.
      • 
                        
    • Generic Workspaces: Never hardcode app paths; inspect dynamically via X-Workspace.
      • 
                        
    • Living Documentation: Always update docs/API.md, FAQ.md, and README.md with any changes.
      • 
                        
    • All Tests Green: Run python3 -m unittest discover tests before submitting pull requests.

    End-to-End Workflow Examples & Architecture Flows 🚀
    
                    
    Practical walkthroughs of common deployment scenarios illustrating the complete data flow from the UI, through the Python REST API, to execution and distribution.
    
                    
    

                    
    Flow 1: First-Time Project Import & Auto-Scan
    
                    
      
                        
    • Directory Inspection: GET /api/deployment/inspect-path?path=/path/to/project detects project layout and monorepos.
      • 
                        
    • Workspace Registration: POST /api/deployment/workspace/allow registers target folder into workspace list.
      • 
                        
    • 1-Click Auto-Scan: POST /api/deployment/scan-all extracts flavors, bundle IDs, and signing keystores.
      • 
                        
    • Dynamic Command Generation: Produces executable cards grouped into Dev, QA, and Prod tabs.
      • 
                    
    

                    
    Flow 2: Multi-Environment Build (Dev / QA / Prod)
    
                    
      
                        
    • Command Selection: Choose application and environment flavor.
      • 
                        
    • Trigger Execution: POST /api/deployment/execute starts background build process in isolated process group.
      • 
                        
    • Streaming Logs: UI polls GET /api/deployment/job?id=<job_id> to stream live output chunks with stopwatch timer.
      • 
                    
    

                    
    Flow 3: Wireless Testing (Camera QR & Multi-Device ADB Push)
    
                    
      
                        
    • Instant Camera QR: Pure Python GF(256) SVG QR code generated at GET /api/deployment/qr?text=<url> for phone camera scan.
      • 
                        
    • Wireless ADB Parallel Push: POST /api/deployment/adb/push installs APK simultaneously across all paired Wi-Fi devices.
      • 
                    
    

                    
    Flow 4: Chained Release Pipeline
    
                    
    
                        Sequential Chain: App Doctor Pre-flight ➔ Flutter Build AAB ➔ Build Size Regression Check ➔ Fastlane Store Upload ➔ Team Webhook Alert.
                    
    
                    
      
                        
    • Triggered via POST /api/deployment/pipelines/run.
      • 
                        
    • Fail-Fast Guard: If any check fails, execution immediately halts to prevent corrupting store tracks.
      • 
                    
    

                    
    Flow 5: Inbound CI/CD & Two-Way ChatOps
    
                    
      
                        
    • Slack / Chat Command: Send /deploy customer_app prod build_aab.
      • 
                        
    • HMAC Verification: Inbound request verified using SHA-256 HMAC secret.
      • 
                        
    • Headless Runner: Triggers build and posts interactive results card back to team channel.
      • 
                    
    
                
    

                
                
    
                    
    REST API Documentation 🔌
    
                    
    The Dev Deployment Console provides a robust REST API powering both the web UI and external automation scripts. The server listens on localhost (default port 18112).
    
                    
    
                    
    Conventions & Security
    
                    
    

    

    
Header / Query
Required
Meaning

    


    X-API-TokenRequiredBearer auth token from ~/.config/dev-deployment/auth_token.txt
    

    ?token= or ?auth=Media OnlyQuery parameter fallback for streaming APKs or rendering QR SVGs
    

    X-WorkspaceOptionalAbsolute directory of target project workspace (defaults to active root)
    

    Content-Type: application/jsonPOSTRequired for all JSON request payloads (except multipart .p8 upload)
    
    

    

    
                    
    Workspaces & Projects
    
                    
    

    

    
Method
Endpoint
Query / Body
Returns / Purpose

    

    GET/api/deployment/workspaces–Returns list of added projects, default workspace, and directory existence check.
    

    POST/api/deployment/workspace/allow{"path": "/path/to/project"}Adds a new project workspace to config/workspaces_list.json.
    

    POST/api/deployment/workspace/remove{"path": "/path/to/project"}Removes a project tab from the console list (source files remain untouched). Returns 409 if a job is running.

    POST/api/deployment/pick{"kind": "folder"|"file"}Opens OS native folder picker dialog on server host and returns selected path.
    

    POST/api/deployment/workspace/select{"path": "/path/to/project"}Sets server-wide default workspace.

Method
Endpoint
Query / Body

Endpoint
Query / Body

    POST/api/deployment/credentials/upload{"filename", "contentBase64", ...}Imports uploaded base64 key directly into user keychain directory.
    

    POST/api/deployment/credentials/remove{"kind", "app"?}Disassociates key mapping from specified application.
