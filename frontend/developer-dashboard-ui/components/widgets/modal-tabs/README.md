# Modal Sub-Tabs Navigation Component (`.ui-modal-tabs`)

Underlined text tab navigation designed for placement within modal body sections or dialog card headers.

## Structure

- `.ui-modal-tabs`: Border-bottom flex row wrapper.
- `.ui-modal-tab`: Individual text tab button. Set active tab with `.ui-active`.

## Usage Example
```html
<div class="ui-modal-tabs">
  <button class="ui-modal-tab ui-active">General Config</button>
  <button class="ui-modal-tab">Steps & Actions</button>
</div>
```
